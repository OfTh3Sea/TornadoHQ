## 📖 About

Rowan's Tornado HQ is a single-file interactive web page packed with everything a young storm enthusiast could want to know about tornadoes. It was designed specifically for someone who lives in Kansas City — right on the edge of Tornado Alley — and wants to learn about the science, safety, and sheer awesomeness of the world's most powerful storms.

The design matches the storm aesthetic of Rowan's other projects (the Tornado Quiz and StormRunner game), with an animated stormy night sky, rain, and lightning flashes.

---

## ✨ Features

- **9 interactive sections** navigated by tab buttons
- **Animated background** — rain, lightning flashes, and a spinning tornado hero icon
- **Expandable content** — tap EF Scale bars and Wow Facts cards to reveal hidden bonus details
- **Accordion glossary** — click any tornado term to expand its definition
- **Zero dependencies** — pure HTML, CSS, and vanilla JavaScript in a single file
- **Mobile friendly** — responsive layout works on phones and tablets
- **Dark theme** — storm-sky aesthetic with yellow lightning accents

## 🚀 How to Use

No installation, no build step, no server needed.

1. Download `rowan-tornado-hq.html`
2. Open it in any modern web browser (Chrome, Firefox, Safari, Edge)
3. That's it — everything runs locally!

```bash
# Or clone the whole repo
git clone https://github.com/your-username/rowans-tornado-hq.git
cd rowans-tornado-hq
open rowan-tornado-hq.html
```

## 📍 A Note on Kansas City

Kansas City, Missouri sits right on the eastern edge of Tornado Alley. Missouri sees around 56 tornadoes per year, with peak season running April through June. The 2011 Joplin EF5 tornado — one of the costliest in US history — struck just 160 miles southeast of KC.

This project was built with that local context in mind, including a dedicated Kansas City section with nearby historic storms, local warning systems, and why the geography makes the region so tornado-prone.
